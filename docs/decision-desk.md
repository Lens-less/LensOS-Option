# 发现、对比与观察

[项目首页](../README.md) · [设计合同](../DESIGN.md) · [贡献指南](../CONTRIBUTING.md)

研究台聚焦 Deribit BTC / ETH **USDC 线性期权**。你先找到可研究的结构，再用同一组假设
比较，最后保留一个需要重新核验的观察。它不访问账户，不下单，不提供手数或仓位建议。
有候选不代表有已验证优势，`execution_allowed=false` 在所有结果中成立。

## 打开研究台

安装后运行：

```powershell
crypto-options-report start
```

浏览器默认自动打开 `http://127.0.0.1:8000/index.html`。这是离线合成演示，合约与报价用于
体验流程，明确标为虚构，不是当前行情或历史结果。`Ctrl+C` 停止；端口占用时加
`--port 8001`，不自动打开浏览器时加 `--no-open-browser`。

点击研究台的“读取公开行情”，即可在同一服务中切换；这一步需要网络，通过 Deribit 公开
接口取数，无需账户或密钥。也可停止当前服务后直接启动该模式：

```powershell
crypto-options-report start --current
```

新研究台当前支持合成 demo 和公开行情。服务始终只监听本机回环地址，本指南不提供在线
服务地址。已有旧快照的历史回放仍在兼容界面，见本页末尾的新旧合同说明。

| 来源 | 能说明什么 | 不能说明什么 |
| --- | --- | --- |
| 离线合成演示 | 产品流程、虚构结构的计算和交互 | Deribit 行情、真实历史、可信优势 |
| 当前公开行情 | 本次实际采集到的合约与报价 | 保证成交、账户适用性或盈利能力 |
| 旧界面的历史回放 | 原有固定输入与采集时点下的研究 | 新研究台历史功能、当前报价或当前资格 |

刷新可能复用仍然有效的快照，原截止时间与标识保持不变。重复点击不能保证新报价。
比较拒绝已过期快照。若采集失败，查看错误并重试，
不会静默换成演示数据。

## 发现：先找到可比结构

选择 BTC 或 ETH，设定方向与到期范围，再按结构宽度和报价价差收窄结果。候选来自
确定性合约组合与筛选规则；同一输入、时钟与条件得到同一结果。排序使用价外程度、结构宽度、
摘要报价价差和剩余天数，按稳定规则处理并列；它不预测收益，不表达 AI 推荐、期望收益或获利概率。

当前结构为看涨 put 信用价差、看跌 call 信用价差和区间 iron condor。每个候选列出精确腿、
到期、入场现金、费用、期权收益边界和排除 / 失效原因。一单位研究结构表示腿的比例，
不要求你交易这个数量。

先看覆盖信息，再读候选：

- **合约登记与摘要扫描**：用完整 registry 和全链摘要筛选支持范围；列出登记数、摘要数和扫描完整性。
- **受限短名单与深报价**：最多保留 48 个结构，进一步读取精确腿报价；单独显示深报价数量与失败原因。
- **明确排除**：inverse、到期不符、单位不支持、缺失或过期双边报价、交叉报价等都保留原因。

筛选策略内的价外卖腿 vertical 配对都计数，condor 对应翼配对完整计数、仅生成受限短名单。
完整摘要扫描不等于每个合约都取得深报价，也不等于穷举所有可能结构。部分响应不能标为
完整扫描。选中的候选须按自身有效期、报价和费用口径判断是否可比。

“没有匹配”说明筛选没有结果；“数据不可用”“流动性受限”“风险 / 单位不支持”说明对应
约束阻断。收窄条件可以改变匹配集合，不能补出缺失报价或替代旧准入证据。

## 对比 / 决定：只改变共同假设

选取 2–3 个同到期的可比候选。它们必须来自同一快照，使用共同的价格变化、经过天数、IV 变化、
费用政策和估值口径。改变假设时一起重算，不让每个候选各用对自己有利的输入。

| 展示内容 | 正确理解 |
| --- | --- |
| 到期收益图 | 假设按指定 USDC 指数结算，扣入场费与逐腿动态交割费；日到期豁免须有明确元数据 |
| 到期前压力情景 | 零利率 / carry、指数作为 forward、冻结当前半价差与标准退出费的理论重估；不是可成交退出报价 |
| 情景损益 | 这个假设成立时的结果，不代表假设会发生 |
| 期权收益损失边界 | 原始期权 payoff 口径，排除所有交易费与交割费，不是总损失保证 |
| 排名 | 公开规则下的确定性比较，不是正 EV、胜率或个人适合度 |

IV 变化使用百分点：50% 加 10 个百分点是 60%。若压力模型缺少必要输入，显示不可计算，
不能填成零或用概率替代。经过天数不能超过共同到期日。没有已验证历史或校准模型时，
不生成历史胜率、预测区间或概率。

决策动作是保留观察或复制研究复核。记录包含精确腿、bid/ask、报价单位与时间、来源、
快照 / 分析 / 假设标识、费用口径、收益边界、有效期和重核条件；不构成订单模板。
剪贴板不可用时可使用页面提供的复核文本手动复制。

## 观察：重新核验同一组腿

观察只保存在当前浏览器，保留原结构、快照和假设，不跨设备同步。手动复核会向本地研究服务
提交原结构，不附本地笔记。它不自动监控，也不记订单、成交、持仓或交易盈亏。清除浏览器
站点数据可能删除这些观察。

重新取数后复核**同一组精确合约**，比较报价、成本和当前可比状态。缺失腿不能替换成相邻
行权价；合约已到期、双边报价缺失、过期或交叉时，明确说明本次不能恢复当前可比状态。
原始观察可作为历史记录保留，其时间和标识不能改成新研究。

复核前取得有效且同步的双边报价，并重新评估共同假设、费用、收益边界及失效条件。
观察到期不是自动交易信号。复制旧观察不能延长它的有效期。

## 看懂单位与成本

原生价格与结算都采用支持合同的 USDC 口径，同时保留合约乘数和腿比例。不得把
BTC/ETH inverse 合约的币本位价格当成 USDC；inverse 在本轮明确排除。
[Deribit USDC 线性期权规格](https://support.deribit.com/hc/en-us/articles/31424932728093-Linear-USDC-Options)、
[inverse 规格](https://support.deribit.com/hc/en-us/articles/31424939096093-Inverse-Options)

卖出参考 bid，买入参考 ask。`entry_cash` 是毛参考权利金，`net_entry_cash` 扣除入场费。
当前费用假设为标准逐腿费用：指数名义的 3 bps、最多为权利金的 12.5%；这是有版本的
研究政策，不是读取你的实际费用。报价带来的相对 mid 损耗与手续费分开：若入场现金已经按
bid/ask 计算，就不能再把同一价差损耗扣一次。费用必须有具体政策与数值；没有账户权限，
不假设 VIP 折扣、账户抵扣或既有仓位抵消。组成多腿研究结构也不意味着能享受实际 combo
成交优惠。原始收益边界排除所有交易费与交割费，情景中的费用计算也不是未来真实费用保证。
[Deribit 费用政策](https://support.deribit.com/hc/en-us/articles/25944746248989-Fees)

## 新旧合同与数据权限

`decision_desk.v1` 的研究可比候选与 `research_comparison.v1` 的情景对比，不提升旧
`research_report.v1`、`strategy_brief.v1` 或 `EntryAdmissionDecision` 的任何门禁。
旧策略卡仍最高为 `WATCH`，历史 `VALIDATED` 与预测 `CALIBRATED` 仍需各自真实证据。
新研究台不能把“结构可研究”写成“已获准执行”。

`?view=legacy` 保留旧界面；既有 `demo`、采集 CLI、API、sidecar 与扩展继续兼容。
`crypto-options-report start --snapshot <path>` 打开旧报告回放，接受原有市场快照格式，
不接受 `desk_market.v1`；它与 `--current` 互斥。刷新只重读本地输入，不取得当前行情。
旧报告采集和固定复现方法见 [历史研究流程](guides/decision-workflow.md)，其内容不是新
研究台的首次使用前置条件。

Deribit 行情及派生数据限定为个人用途，其他聚合、发布或转发需事先书面许可。代码开源
和仓库数据许可不能替代来源授权。观察默认仅供本机个人研究；公开 issue、PR 截图和
演示使用合成或已有授权的数据，不附原始行情、账户资料或私有证据。
[Exchange Terms §2.10](https://support.deribit.com/hc/en-us/articles/25944532191645-Deribit-Exchange-Membership-Terms-Deribit-FZE)、
[Panama Terms §32.3](https://support.deribit.com/hc/en-us/articles/25944471089437-Terms-of-Service-DRB-Panama-Inc)

完整流程的成果是可解释、可对比、可重核的研究观察。它不要求每次有候选，也不证明策略能盈利。
