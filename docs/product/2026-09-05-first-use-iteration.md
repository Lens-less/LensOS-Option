# 首次使用与状态一致性迭代

本轮基于 2026-09-05 的本地代码审查和浏览器复现。目标是让用户可以完成离线学习、理解证据状态，并在加载失败后自行恢复。

## 范围与边界

- 修复当前有效性与快照计算结论的冲突，覆盖实时、回放、演示和公开版。
- 提供独立的离线教学导览；教学内容不进入研究报告，不伪造 VALIDATED / CALIBRATED，不提升任何门禁。
- 补齐原因解释、首次连接和失败后重试。
- 从最终 wheel 验证浏览器用户流程，同步贡献检查入口及当前产品文档。
- 保留 research_only、NO_TRADE 和 execution_allowed=false；不接入交易，不提交或发布远端。
- 不引入新的项目依赖。本轮不包含核心分析架构迁移、稳定公开 schema 或研究模型提升。

## 修改前计划

1. 在实际消费报告的页面边界写过期回归，确认旧页面仍暴露当前资格的失败；最小化修复共享显示状态与消费者。
2. 在加载器和错误边界写超时、异常后有效数据恢复测试，再实现有限等待和明确重试。
3. 复用现有原因目录，补齐缺失投影，过滤正常信息项，不另造状态系统。
4. 教学导览采用独立数据与组件，完成选择示例、理解风险、查看依据三个动作；真实报告保持原有 fail-closed 行为。
5. 添加可重复的浏览器验收和统一验证入口，更新产品文档；构建后同步 wheel 内置前端。

## 验收接口

- 报告 → EvidenceConsole / workbench：固定报告与显式时钟，过期后无当前可用资格；历史内容明确标记计算时刻。
- HTTP loader → App / PublicApp：网络失败、超时和不合法报告撤下旧结果，有效重试可恢复。
- SidePanelApp：首次连接和错误说明不藏在默认折叠的依据里。
- demo CLI → 安装后的浏览器页面：导览可离线完成，可返回真实阻断快照，始终区分教学与研究。
- CI：Python / Web 测试、lint、构建、公开 bundle 边界、扩展产物和浏览器流程。

## 清理原则

先用回归锁住用户行为，再删除重复判断或复用现有辅助函数。按职责做小范围修改，不引入规则引擎，不借此次迭代重写核心分析。

## 完成记录

### 已实现

- 演示入口默认进入三步离线导览：选择结构、拖动到期价格观察损益、理解证据限制。牛市看跌价差、熊市看涨价差与铁鹰均为独立的标准化教学算例；完成后可进入安装包随附的阻断快照。
- 主站、公开页、工作台与 Chrome 伴侣统一处理失效和质量阻断：撤下当前数值、候选和资格，保留明确标注计算时间的历史证据。公开版保留自身 `stale_after` 时效；简报自身到期仅称为简报暂停。
- 复用原因目录，补齐市场状态解释和操作方向，将无持仓、未请求模拟等正常信息收进次要说明。
- 主报告和附属工件共用有界请求，区分网络、超时、服务响应和校验失败；刷新重试可重新取得有效输入。首次连接与错误说明直接可见。
- 新增 `python tools/verify.py`，将源码检查、三种前端构建、最终 wheel 隔离安装与浏览器流程连成同一入口；CI 和发布流程在最终前端构建后验证 wheel。
- 同步中英文 README、设计说明、架构地图和贡献流程，删除已解决的结构债描述，明确当前源码与既有 v0.4.0 发布包的差别。
