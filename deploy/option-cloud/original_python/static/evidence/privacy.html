Privacy / 公共静态页

隐私政策

公开站以静态方式交付，不设置账户，不放第三方追踪脚本，也不收集用户资料。

我们不收集什么

  • 不设置 cookie，不要求登录，不建立用户账户。
  • 不接入第三方分析、广告或追踪脚本。
  • 不主动加载第三方字体、图片或嵌入资源。

托管层日志

静态主机仍可能按自身政策记录常规 HTTP 元数据，例如 IP 地址、用户代理、请求路径和时间戳。 这些日志由托管商控制，不由公开站前端主动收集。

本地伴侣

本页只描述公开静态站。若启用本地 Chrome 伴侣，它只在本机 loopback 上工作，不属于公开站的 追踪边界。
