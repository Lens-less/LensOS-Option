Methodology / 公开研究口径

方法页

这页说明公开站如何发布、如何定义头条、如何标注证据，以及哪些问题只能放在二级披露里。

发布方式

公开版本是一个确定性的静态快照。它由捕获时刻和预计算研究工件生成，生成后只读，不在浏览器里再 重算市场结论。

头条口径

公开头条默认滞后一日，只使用已经收盘的日线数据。这样可以避免同一天重复采集时，头条因为日内刷新而 变成两个版本。

数据来源

  • Deribit 公共 API：期权链、DVOL、市场状态。
  • 自采标的日线：用于 VRP、RV30 和历史分布。
  • 生成的研究工件：用于候选、释放门和公开摘要。

时间对齐以捕获时钟为硬上限：标的日线按真实收盘可用时刻入库，DVOL 保留自己的观测时刻， 只在两者都已可得的最近共同评估日计算。DVOL 是前瞻隐含波动率，RV30 是向后看的 30 日已实现波动率； 两者窗口不同，页面会同时披露观测时刻、评估日与有效样本量。

证据分级

  • trusted：已验证，可作为结论依据。
  • degraded：可读但不足以支撑结论。
  • untrusted：存在但校验失败。
  • missing：不存在。
